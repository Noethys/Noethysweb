Reporter les soldes sur la période suivante

Le solde de chaque collaborateur sur la période choisie est ajouté comme droit « Report » sur la période suivante. Indispensable pour un compte épargne-temps, utile pour les reliquats de congés. Les collaborateurs dont le solde a déjà été reporté sont ignorés.
