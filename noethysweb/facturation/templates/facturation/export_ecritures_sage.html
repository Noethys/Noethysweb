Fonctionnalité expérimentale : vérifier les résultats obtenus pour toute utilisation en production.

Avant l'export, vous devez avoir au préalable renseigné les informations suivantes :

  • Menu Paramétrage > Modes de règlements : Le compte comptable et le code journal de chaque type.
  • Menu Paramétrage > Activités : Le compte comptable et le code analytique (Optionnel) de chaque activité.
  • Menu Paramétrage > Type d'adhésion : Le compte comptable et le code analytique (Optionnel) de chaque type.
  • Fiche famille > Paramètres : Le compte comptable de la famille (Optionnel). A défaut, un code de type "FAM000001" sera généré automatiquement.

Version de Sage : l'import des écritures dans Sage est paramétrable (les colonnes du fichier sont mappées dans votre logiciel via le menu Fichier > Format import/export paramétrable). Le choix de la version pré-règle les conventions adaptées :

  • Sage 50 / Sage 50cloud (ex-Ciel) et Sage Ligne 30 / i7 : section analytique sur une simple colonne.
  • Sage 100 / 100cloud : comptes sur 8 caractères (ex : 41100000), section analytique sur une simple colonne.
  • Sage 100 - Analytique par doublement : chaque ligne de produit (classe 7) est doublée d'une ligne analytique (colonne Type = G pour la générale, A pour l'analytique), avec le n° de plan et la section, conformément au fonctionnement de l'analytique Sage 100.

Les résultats de l'export seront les suivants :

  • Les factures dont la date de génération est comprise dans la période sélectionnée.
  • Les règlements dont la date de dépôt est comprise dans la période sélectionnée.

Les résultats seront exportés sous la forme d'un unique fichier CSV à importer dans Sage. Les colonnes générées peuvent être mappées dans le format d'import paramétrable de Sage.
